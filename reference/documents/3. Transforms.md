# 3. Transforms

Transforms are utilities that use create a different representation of an underlying data type.

```ts
const user = st.object({
    id: st.asHex(st.fixedBytes(8)),
    createdAt: st.asDate(st.f64()),
});
```

## Writing your Own

Here is the `transform` pipeline function, it takes a serializer and returns a serializer

```ts
export function asHex<const T>(type: st.Serializer<UInt8Array>): st.Serializer<string> {
    return {
        size: type.size,
        read: (ctx) => {
            const data = type.read(ctx);
            return data.toHex();
        },
        write: (ctx, value) => {
            const data = Uint8Array.fromHex(value);
            type.write(ctx, data);
        },
    };
}
```

For most cases, the `st.encode` helper can manage this for you

```ts
export function asHex(type: st.Serializer<Uint8Array>): st.Serializer<string> {
    return st.encode(type, {
        encode: (v) => Uint8Array.fromHex(v),
        decode: (v) => v.toHex().toUpperCase(),
    });
}
```
