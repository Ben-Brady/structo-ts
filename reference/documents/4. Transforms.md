---
title: 4. Transforms
---

Transforms are utilities that use create a different representation of an underlying data type.

```ts
const user = st.object({
    id: st.asHex(st.fixedBytes(8)),
    createdAt: st.asDate(st.f64()),
});

st.write()
```


## Included Transforms

These are the transforms that are shipped with the standard library, it's easy to write your own if your not able to use one

| Name             | Type                          | Description                      |
|-----------------------|-------------------------------|------------------------------------|
| **`st.asDate`**       | `number` -> `Date`            | Store a `Date` type as a number  |
| **`st.asAscii`**      | `Uint8Array` -> `string`      | Interpret bytes as an ascii string |
| **`st.asUtf8`**       | `Uint8Array` -> `string`      | Interpret bytes as a UTF-8 string |
| **`st.asBase64`**     | `Uint8Array` -> `string`      | Read/write bytes as a base64 string |
| **`st.asHex`**        | `Uint8Array` -> `string`      | Read/write bytes as a hex string |
| **`st.asBytes`**      | `Uint8Array` -> `number[]`    | Read/write bytes as `number[]` |
| **`st.asTypedArray`** | `Uint8Array` -> `TypedArray`  | Reinterpreter bytes as a typed array such as  `Float32Array` |


## Writing your Own


For most cases, the `st.encodeAs` helper can manage help you write a transform pipeline

```ts
export function asHex(type: st.Serializer<Uint8Array>): st.Serializer<string> {
    return st.encodeAs(type, {
        encode: (v) => Uint8Array.fromHex(v),
        decode: (v) => v.toHex().toUpperCase(),
    });
}
```

However, if you need performance or something `encodeAs` doesn't support,
here is the full outlined transform function.

It simply takes in a serializer and produces one, using the provided type to do the actual writing/reading

```ts
export function asHex(type: st.Serializer<UInt8Array>): st.Serializer<string> {
    return {
        size: type.size,
        read: (ctx) => {
            const value = type.read(ctx);
            return value.toHex();
        },
        write: (ctx, value) => {
            const data = Uint8Array.fromHex(value);
            type.write(ctx, data);
        },
    };
}
```
