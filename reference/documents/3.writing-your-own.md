# 3. Writing Your Own Serializers

Here is an example:
```ts
function bytes(size: number): Serializer<UInt8Array> {
    return {
        size: size, // Specifying the size lets you allocate the type in advance
        write: (ctx, value) => {
            ctx.reserve(size); // Ensure that there is enough space ahead of the current pointer to write to
            ctx.bytes.set(value, ctx.offset)
            ctx.offset += size; // Increment the data point so anything writen after doesn't overrite this
        },
        read: (ctx) => {
            const value = ctx.bytes.slice(ctx.offset, ctx.offset + size); // read the data from ctx.bytes buffer we are given
            ctx.offset += size; // increment the point to the end of the data
            return value;
        },
    }
};

st.object({
    id: bytes(8),
})
```

`WriterContext` and `ReaderContext` mostly overlap, with the only difference being that `WriterContext` has access to .reserve

## Object Error Reporting

`pushPath`/`popPath` are provided to help give proper error messages when encoding objects and arrays.

```ts
for (let i = 0; i < value.length; i++) {
    ctx.pushPath(i);
    type.write(ctx, value[i]);
    ctx.popPath();
}
```

The API is entirely optional to use, your code will still work fine without it. But it does provide a better experience when things go wrong.

## Testing

When writing a custom serializer, it's a good idea to make sure it doesn't break

If your using a library that's jest compatible, you can use `st.createTestingUtils` to get a set of helpers to make testing easier. If you want to an example of serializers see [the standard library](https://github.com/Ben-Brady/structo-ts/blob/main/src/object/object/object.test.ts).

```ts
import { st } from "@nnilky/structo";
import { describe, expect, it } from "test-library";
export const {
    assertEncodesAndDecodes,
} = st.createTestingUtils(expect);

describe("st.object", () => {
    it("encodes correctly", () => {
        assertEncodesAndDecodes({
            serializer: st.object({
                a: st.u8(),
                b: st.u8(),
            }),
            value: { a: 1, b: 2 },
        });
    });
});
```
