# 2. Pipelines

Pipelines let you generate transforms on your date when reading/writing, this lets you have you data represented at runtime differnetly to how they're stored


```ts
st.object({
    floats: st.pipe(
        st.bytes(st.u16()),
        st.toTypedArray(Float32Array),
    )
})
