# 1. Quickstart

```ts
npm install @nnilky/structo
```

```ts
import { st } from "@nnilky/structo";

const User = st.object({
    name: st.string(st.u32()),
    age: st.f32(),
})

const bytes = st.write(User, { name: "nnilky", age: 23.1 })
const user = st.read(User, bytes)

const buffer = new ArrayBuffer(1024)
st.writeInto(buffer, 0, User, { name: "Ben Brady", age: 23.6 })
```

## `st.writeInto`

If you wanna write into an existing buffer (such as with WASM and WebGL/WebGPU) you can use `st.writeInto`

```ts
const buffer = new ArrayBuffer(1024)

let offset = 0
offset += st.writeInto(buffer, offset, User, {
    name: "nnilky",
    age: 23.1,
})
offset += st.writeInto(buffer, offset, User, {
    name: "Ben Brady",
    age: 23.6
})
```

For more information see the [st.writeInto documentation](/functions/index.writeInto.html)
