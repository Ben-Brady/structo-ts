# 1. Quickstart

## Installation

```ts
npm install @nnilky/structo
```

## Create a Schema

Define your own schema, see [Types](./2.%20Types.md) and the reference section for available types.

```ts
import { st } from "@nnilky/structo";

type User = st.Infer<typeof User>; // optional type definition
const User = st.object({
    name: st.string(st.u32()),
    age: st.f32(),
});
```

## Read / Write into a new buffer

Use `st.write` and `st.read` to read and write into new buffers

```ts
const bytes: ArrayBuffer = st.write(User, {
    name: "nnilky",
    age: 23.1
});

const user = st.read(User, bytes);
```

## Read / Write into an existing buffer

Use `st.writeInto` and `st.read(offset)` to read from existing buffers, this is useful for WASM & WebGL/WebGPU.

```ts
const buffer = new ArrayBuffer(1024)

// The second parameter denotes the offset into the buffer
st.writeInto(buffer, 0, User, {
    name: "Ben Brady",
    age: 23.6,
});
st.writeInto(buffer, 128, User, {
    name: "nnilky",
    age: 23.2,
});

// The last parameter is optional, but denotes the offset
const user1 = st.read(buffer, User, 0);
const user2 = st.read(buffer, User, 128);
```

## Full example

```ts
import { st } from "@nnilky/structo";

type User = st.Infer<typeof User> // optional type definition
const User = st.object({
    name: st.string(st.u32()),
    age: st.f32(),
})

// Single Buffer

const bytes = st.write(User, {
    name: "nnilky",
    age: 23.1
});

const user = st.read(User, bytes);

// Shared Buffer

const buffer = new ArrayBuffer(1024)
const bytes = st.writeInfo(User, {
    name: "nnilky",
    age: 23.1
});

// The second parameter denotes the offset into the buffer
st.writeInto(buffer, 0, User, {
    name: "Ben Brady",
    age: 23.6,
});
st.writeInto(buffer, 128, User, {
    name: "nnilky",
    age: 23.2,
});

// The last parameter is optional, but denotes the offset
const user1 = st.read(buffer, User, 0);
const user2 = st.read(buffer, User, 128);
```
