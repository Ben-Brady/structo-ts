# 2. Types

## Numbers

- **`st.f16` / `st.f32` / `st.f64`**
    - Floating point types
- **`st.u8` / `st.u16` / `st.u32` / `st.u64`**
    - Unsigned integer types
- **`st.s8` / `st.s16` / `st.s32` / `st.s64`**
    - Signed integer types
- **`st.s64BigInt` / `st.u64BigInt`**
    - BigInt types for 64bit values, allowing read/writing of values above `number` limits.

## Strings

- **`st.string`**
    - A dynamic string, prefixed with it's length

## Bytes

- **`st.bytes`**
    - A dynamic set of bytes, prefixed with it's length
- **`st.fixedBytes`**
    - A fixed amount of bytes

## Object

- **`st.object`**
    - Standard struct type, values are encoded in order
- **`st.fastObject`**
    - A faster implementation of object using eval
- **`st.packedBits`**
    - Packed bits of integers across a series of bytes

## Array

- **`st.array`**
    - A dynamic length array with a written length
- **`st.fixedArray`**
    - A fixed length array, must have a static size
- **`st.exhaustiveArray`**
    - An array that writes until the until of the file
