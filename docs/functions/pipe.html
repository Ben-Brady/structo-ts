    Function pipe

    st.pipe is the designed entrypoint for pipeline functions, it lets you write a pipeline from exit

    st.object({
      age: st.u32(),
      ageInMonths: st.pipe(
        st.u32(),
        st.modify(v => v * 12),
        st.offset("relative", -8),
      )})
